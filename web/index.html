BYD 仪表飞屏助手

通过车机自带的 ClusterDebug 调试工具，打开 DiLink 4.0「18.x 控制器」隐藏的仪表全屏导航

连接车机（无线 ADB）

未连接
前置条件：车机「开发者选项」里打开 连接USB后启用调试模式 与 无线ADB调试； 电脑连上车机热点（或同一局域网）。首次连接车机会弹授权，勾选「始终允许」。
连不上、报 connection refused / 超时？多半是设备处于 Android 11+ 的 「无线调试」模式 —— 它用 TLS 加密 + 37000~45000 的随机端口， 不监听 5555，普通程序连不上。
解法：用 USB 线把设备连到这台电脑、在设备上允许 USB 调试，然后点上面这个按钮， adbd 就会改回 5555 明文监听（重启设备后失效，需重做）。
比亚迪车机不用走这一步 —— 它的「无线 adb 调试」开关本身就是 5555 明文。

飞屏开关

「开启飞屏」= 启动 ClusterDebug 代理 → 仪表导航类型设为全屏(4) → 触发投影(35→16) → 启动定制版地图。
